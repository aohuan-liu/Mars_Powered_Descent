 # 论文+代码 入门指南
 
 ## 先说清楚三件事
 
 ### 这篇论文到底在干什么？
 
 **一个航天器从火星高空掉下来，需要控制发动机推力让它准确降落到指定地点，还要绕开地上的石头。**
 
 你需要找出一条"推力随时间怎么变"的曲线，使得：
 1. 落地时速度正好为零（不然就摔碎了）
 2. 落在指定位置（不能偏）
 3. 燃料用得越少越好
 4. 绕过障碍物
 
 **论文做的就是"怎么找到这条最优曲线"。**
 
 ### 什么是"做项目"？
 
 不是让你发明新方法。是让你：
 1. **理解** 论文里的方法
 2. **复现** 论文的仿真结果（用MATLAB写出同样的算法，跑出同样的轨迹图）
 3. **改进** 一点点（加上NN加速）
 
 做完这三步，你就有了一个完整的技术项目。
 
 ### 论文和代码的关系
 
 论文有数学公式，代码就是把公式翻译成计算机能算的形式。
 
 ```
 论文公式（式1） → 代码 mars_dynamics.m    ← 航天器怎么飞
 论文公式（式10-12） → solve_fuel_optimal.m ← 怎么把问题变简单
 论文公式（式20-23） → solve_fuel_optimal.m ← 怎么让计算机算
 论文公式（Problem 4）→ solve_fuel_optimal.m ← 最终求解
 ```

 ## 第二步：读"问题描述"（第2节，2页）
 
 翻到论文第2页 "2. Problem formulation"，看到图1。
 
 ### 你需要看懂的就三样东西：
 
 **1. 坐标系**
 打开 `mars_params.m` 第4行附近：
 ```matlab
 params.r0 = [1500; 0; 1500];  % 初始位置：高度1500m，北向1500m
 params.v0 = [-75; 0; 70];     % 初始速度：向下75m/s，北向70m/s
 ```
 x = 高度（向上为正），y = 东，z = 北。看论文图1，就是这个坐标系。
 
 **2. 状态量和控制量**
 
 ```
 状态 = 航天器当前在哪儿、飞多快、剩多少油 → 7个数
 控制 = 发动机推力朝哪个方向、多大 → 3个数
 ```
 
 **3. 约束条件**
 打开 `mars_params.m`，找到：
 ```matlab
 params.T_max = 13258.17;   % 发动机最大能推多少
 params.T_min = 4971.82;    % 发动机最小推力（不能关，只能调小）
 params.rf = [0;0;0];       % 必须落到原点
 params.vf = [0;0;0];       % 落地速度必须为零
 ```
 
 看完这段，你就知道代码里的这些参数在说什么了。

 ## 第四步：读核心求解器（不需要全部看懂）
 
 打开 `solve_fuel_optimal.m`，先跳到**第85行附近**，看这一段：
 
 ```matlab
 cvx_begin quiet
     variable X(7, N+2)     % 我要找的"状态"
     variable u(3, N+1)     % 我要找的"控制"
     variable sig(1, N+1)   % 辅助变量
     
     minimize(obj)          % 目标：燃料最少
     
     % 约束
     X(:, k+1) == Ad*X(:, k) + ...  % 航天器运动规律
     X(1:3, 1) == r0;               % 初始位置
     X(4:6, 1) == v0;               % 初始速度
     norm(u(:, k)) <= sig(k);       % 推力上限
     T_min * ... <= sig(k);         % 推力下限
 cvx_end
 ```
 
 翻译成人话：
 ```
 让计算机帮我找一串"推力指令"——
     1. 遵守物理规律（动力学约束）
     2. 从指定起点飞到指定终点（边界约束）
     3. 推力不超出发动机能力（推力约束）
     4. 全程燃料最少（目标函数）
 ```

 ## 读不懂英文论文怎么办？
 
 这篇论文全文18页，你只需要读：
 - 第1页：摘要（已经知道了）
 - 第2-3页：问题定义（状态、控制、约束）
 - 第8页：Table 1 & 2（参数表）
 
 剩下的全是推导细节，**暂时跳过**。
 
 如果英文公式读着有困难，用浏览器打开论文PDF，
 用 Edge 的"沉浸式阅读"或者截屏用手机翻译看公式说明。
 
 公式符号说明：
 - r(t) = 位置（position）
 - v(t) = 速度（velocity）
 - m(t) = 质量（mass）
 - T(t) = 推力（thrust）
 - g_m = 火星重力加速度
 
 **读完这三个地方（共3页），你就已经比90%的本科生更了解这篇论文了。**
