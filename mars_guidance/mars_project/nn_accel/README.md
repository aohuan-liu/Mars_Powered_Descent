# NN 加速拓展（方法论待修正）

⚠️ 本目录是**自主拓展**，不是论文内容，目前**不可用**，请在学习主线时忽略。

| 文件 | 说明 |
|---|---|
| `train_nn_approximator.m` | Deep Learning Toolbox 版（生成大量"状态→最优控制"样本训练网络） |
| `train_nn_simple.m` | 简易版（feedforwardnet），供没有 Deep Learning Toolbox 时使用 |

## 为什么当前不可用（ROADMAP 已记录）

1. 用**开环最优轨迹**（固定初始条件一次性求解的结果）当训练数据，
   训练出的网络**不是反馈策略**：真实飞行中状态会偏离，网络没有
   "纠正能力"。
2. 训练数据只覆盖单一初始条件，泛化性没有验证。

## 正确做法（修正后的路线）

1. 先把求解器 **MPC 化**（滚动时域闭环，每个控制周期重新求解）；
2. 在闭环内对**多种初始条件**滚动采样，收集（当前状态 → 当前最优控制）
   数据；
3. 再用这些闭环数据训练 NN 作为策略近似；
4. 最后对比 NN 与 MPC 的闭环性能（落点误差、燃料、鲁棒性）。

在完成 MPC 化之前，这两个文件的输出不应作为任何结论的依据。
